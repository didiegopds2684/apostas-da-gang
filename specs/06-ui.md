# Spec 06 — UI (Frontend)

## Objetivo

Definir as páginas, rotas e componentes principais do frontend React.

## Rotas

| Rota | Componente | Auth? |
|---|---|---|
| `/` | Redirect → `/dashboard` ou `/login` | — |
| `/login` | `LoginPage` | Não |
| `/dashboard` | `DashboardPage` | Sim |
| `/games` | `GamesPage` | Sim |
| `/games/:id` | `GameDetailPage` | Sim |
| `/groups` | `GroupsPage` | Sim |
| `/groups/new` | `CreateGroupPage` | Sim |
| `/groups/join` | `JoinGroupPage` | Sim |
| `/groups/:id` | `GroupDetailPage` | Sim |
| `/groups/:id/ranking` | `RankingPage` | Sim |
| `/profile` | `ProfilePage` | Sim |

## Páginas

### `LoginPage`

- Logo + nome do app
- Botão "Entrar com Google" (chama `signIn()` do `AuthContext`)
- Estado de loading durante autenticação
- Sem campos de email/senha

### `DashboardPage`

- Saudação com nome e avatar do usuário
- Cards de resumo:
  - Total de palpites registrados
  - Próximo jogo sem palpite
  - Minha melhor posição nos grupos
- Atalhos para `/games` e `/groups`

### `GamesPage`

- Tabs de filtro: "Todos" | "Fase de grupos" | "Eliminatórias"
- Filtro por data (datepicker simples)
- Lista de `GameCard` ordenada por `startsAt`
- Indicador visual de status: `NS` (cinza), `LIVE` (verde pulsando), `FT` (azul)

### `GameCard` (componente)

```
┌─────────────────────────────────────┐
│  [🇧🇷] Brasil    2 : 1   Argentina [🇦🇷] │
│  15/06 · 15h00 · Fase de Grupos C   │
│  Seu palpite: 2-1 ✓  [3 pts]       │
└─────────────────────────────────────┘
```

- Bandeiras via URL da api-football
- Input de palpite inline (dois campos numéricos) se prazo aberto
- Cadeado se prazo fechado
- Badge de pontuação após jogo terminar

### `GroupsPage`

- Lista dos grupos do usuário
- Botão "Criar grupo" → `/groups/new`
- Botão "Entrar com código" → `/groups/join`
- Card de cada grupo com nome, nº de membros, minha posição

### `GroupDetailPage`

- Nome do grupo
- Código de convite (visível para admin com botão de copiar)
- Botão "Compartilhar link" (copia link com convite)
- Lista de membros
- Link para `/groups/:id/ranking`

### `RankingPage`

- Tabela de ranking do grupo
- Linha do usuário autenticado destacada
- Ícones de medalha para top 3
- Atualização automática a cada 5 minutos

### `CreateGroupPage`

- Campo de nome do grupo
- Botão "Criar"
- Após criar: redireciona para `/groups/:id` com toast "Grupo criado!"

### `JoinGroupPage`

- Campo de código de convite (uppercase automático)
- Botão "Entrar"
- Após entrar: redireciona para `/groups/:id`

## Componentes compartilhados

| Componente | Descrição |
|---|---|
| `Navbar` | Header com logo, nav links, avatar do usuário e botão de logout |
| `Avatar` | Foto circular com fallback para iniciais |
| `Toast` | Notificações de sucesso/erro (usar react-hot-toast) |
| `LoadingSpinner` | Spinner centralizado para estados de carregamento |
| `ErrorMessage` | Exibição de erros de API com botão de retry |
| `Badge` | Badge de pontos (verde ≥1, cinza =0, cinza claro =null) |
| `ScoreInput` | Par de inputs numéricos para palpite com validação |

## Estado global (Contexts)

### `AuthContext`

```typescript
interface AuthContextType {
  user: User | null
  loading: boolean
  signIn: () => Promise<void>
  signOut: () => Promise<void>
}
```

### Gerenciamento de servidor

Usar **TanStack Query** (React Query) para:
- Cache e sincronização das chamadas à API
- Estados de loading/error automáticos
- Invalidação de cache após mutações (ex: após registrar palpite, invalidar `games`)

## Design

- **Paleta**: verde da Copa (#006233), amarelo (#FFD700), branco, cinza escuro
- **Font**: Inter (Google Fonts)
- **Mobile-first**: layout em coluna no mobile, grid no desktop
- **Dark mode**: não obrigatório em v1, mas evitar cores hardcoded
